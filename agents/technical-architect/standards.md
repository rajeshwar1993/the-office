# Global Engineering Standards

*This file defines the "Law" for all coding agents in this organization.*

## 1. Coding Patterns
- **DRY (Don't Repeat Yourself):** Extract common logic into shared utilities.
- **Error Handling:** Every API call must be wrapped in a try-catch block with meaningful logging.
- **Naming Conventions:** camelCase for variables; PascalCase for classes; SCREAMING_SNAKE_CASE for constants.

## 2. Documentation
- Every function must have a doc eg JSDoc or DartDoc comment explaining inputs, outputs, and side effects.
- Complex logic must be explained with inline comments.
