# Sentinel’s Master Checklist

- [ ] **Functional:** Does the code solve the problem?
- [ ] **Security:** Are there any leaked keys or unauthenticated endpoints?
- [ ] **Naming:** Do variable names make sense (e.g., `userProfile` vs `data1`)?
- [ ] **DRY:** Is there copy-pasted code that should be a shared utility?
- [ ] **Tests:** Are there unit tests? Do they cover the edge cases?
- [ ] **Documentation:** Are complex logic blocks explained in comments?
- [ ] **Standards:** Does the code match the `coding_standards.md` of the respective agent?
